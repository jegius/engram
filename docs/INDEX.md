## 3. Соглашения

**Статусы документов:**
- `Draft` — пишется, можно менять свободно.
- `Review` — на ревью у владельца и лидов.
- `Approved` — зафиксирован; изменения через ADR.
- `Superseded` — заменён новым документом (ссылка обязательна).

**Ссылки:** относительные, в формате `[01. Канон](01-canon.md)`; ссылки на разделы — `[01. Канон](01-canon.md), раздел 8`.

**Числа:** только из [01. Канон](01-canon.md). Новые числа — через «Предложения к канону» в конце документа и ADR.

**ADR:** решения по движку, архитектуре, форматам данных — в `docs/adr/NNN-название.md`; шаблон: контекст → варианты → решение → последствия.

**Язык:** русский; технические термины по глоссарию, английский эквивалент в скобках при первом упоминании.

**Объём:** 1 800–3 500 слов на доменный документ; канон и справочники — без ограничения.
