## 1. Назначение и область

Документ описывает физическое ядро проекта — библиотеку `Engram.Sim` (см. [03](03-architecture.md)): уровни симуляции, интеграторы, столкновения, астрофизические события, допуски точности. Числа берутся из [01 Канон](01-canon.md) и не переопределяются. Вне области: рендер и VFX ([11](11-art-ux-audio-narrative.md)), характеристики оружия ([08](08-combat.md)), экономические последствия ([06](06-economy.md)), репутационные ([09](09-reputation-diplomacy.md)).

## 2. Цели и ограничения

1. **Физика = геймплей.** Игрок предсказывает результат по формулам, а не по мультику: разогнал астероид — знает энергию импакта; встал на пращу у ЧД — знает риск.
2. **Числа канона соблюдаются буквально:** 10⁴⁴ Дж у сверхновой, 2,24×10³² Дж у Земли, ≤ 500 тел, ≤ 10⁻⁴ а.е. на 10 лет.
3. **Детерминизм:** seed + ввод = результат в пределах платформы/сборки (канон 17).
4. **Производительность:** L0 ≤ 20 мс/сутки на 8 ядрах, активная система ≤ 500 тел, загрузка ≤ 15 с.
5. **Автономность:** события идут без игрока и попадают в новости ([06](06-economy.md), [07](07-civilizations-tech-politics.md)).

**Допущения space opera (не объясняются физикой, но имеют правила и цену):**

| Допущение | Правило | Почему |
|---|---|---|
| FTL «Сдвиг» | уравнениями не решается; коридор, стоимость, хроно-долг — канон 7.3–7.5 | физика не «объясняет» FTL |
| Белые дыры | маркер space opera: выброс материи, нестабильность | 3 объекта канона 6.6 |
| Стоп-контур, компенсаторы | внешние поля, граничные условия | геймплейные барьеры |
| Реликты Эхо | не объясняются до конца игры | нарративная рамка |

## 3. Уровни L0–L3 и их стыковка

| Уровень | Состояние | Шаг | Разрешение | Владелец |
|---|---|---|---|---|
| **L0 Мета** | галактика: экономика, политика, экспансия, события, **эфемериды** | 1 игровые сутки (86 400 с) | 2 500 систем | `GalaxyState` |
| **L1 Система** | N-body: светило + планеты + луны + пояса, столкновения, сверхновые | адаптивный 0,25–3 600 с | ≤ 500 тел | `SystemState` |
| **L2 Локальный** | корабль, снаряды, обломки, стыковка, бой | 1/60–1/10 с | ≤ 20 000 сущностей | `LocalState` |
| **L3 Поверхность** | зоны миссий, разрушение, персонажи, погода | 1/30–1/60 с | 2–8 км² | `SurfaceState` |

Правила стыковки:

1. **Вышестоящий не ждёт нижестоящего** (канон 6.1). L0 тикает всегда; отставший L1 догоняет на следующих кадрах, визуально маскируется интерполяцией.
2. **Переходы только на границах тика** — транзакционно, с откатом при ошибке; у тела ровно один владелец (промоушен и демоушен — копирование).
3. **Контракт непрерывности:** повторная активация даёт ‖Δr‖ ≤ 10⁻⁴ а.е. (1,5×10⁷ м), ‖Δv‖ ≤ 10⁻⁶ v_orb — то же число, что канонная точность эфемерид; прогон L1(t₀→t₁) совпадает с эфемеридой L0(t₁) в этом допуске, иначе система помечается нестабильной.

Бюджеты (базовый темп 1× = 2 реальные секунды на игровой час, канон 7.2; при 40× сутки = 1,2 с):

| Уровень | Бюджет | Примечание |
|---|---|---|
| L0 | ≤ 20 мс на игровые сутки | канон 17 |
| L1 | ≤ 8 мс на шаг при 500 телах; ≤ 0,5 мс при 20 планетах | 24 шага по 3 600 с за 1,2 с при 40× |
| L2 | ≤ 4 мс на кадр при 2 000 сущностей | 16,6 мс на кадр всего |
| L3 | ≤ 6 мс на кадр | разрушаемость на воркерах |

## 4. Системы координат, единицы, время

| Система | Начало | Оси | Единицы | Пользователи |
|---|---|---|---|---|
| **G** галактическая | центр Галактики | плоскость диска | пк | карта, навигация, L0 |
| **S** системная | барицентр | эклиптика узла, фиксированная эпоха | а.е. | L1, эфемериды |
| **P** планетоцентрическая | центр планеты | экватор планеты | км | луны, посадка |
| **L** локальная | камера/корабль (floating origin) | мировые оси S со сдвигом | м/см | L2, L3, рендер |

`r_S = r_P + r_planet_S`, `r_L = r_S − origin`. Внутренние расчёты — только в S и double; float допустим лишь для рендер-позиций с ошибкой ≤ 1 см на 8 км.

**Floating origin.** Float32 на дистанциях до 200 а.е. (3×10¹³ м) даёт квант ~2×10⁶ м — недопустимо. Поэтому физика в double (S), камера в начале координат, offset вычитается перед шейдерами; перебазирование при |r_L| > 8 000 м (L3 — 1 000 м) на границе кадра.

**Единицы.** Внутри — СИ, double (канон 8.1); в JSON — суффикс в имени поля (`_au`, `_kg`, `_j`); в интерфейсе — а.е., св. годы, массы Земли/Юпитера, тротил ([18](18-glossary-formulas.md)).

**Время.** Единая шкала — синхрон, секунды от 2317.0 (канон 7.4). Бортовое время: `t_ship = t_gal/γ`, `γ = 1/√(1 − β²)`, где `t_gal` — галактическое время, `t_ship` — собственное время энграмм, `β = v/c`. Для 0,99c γ ≈ 7,09.

## 5. Интеграторы

### 5.1 Почему симлектический

Орбитальная динамика гамильтонова: несимлектический интегратор даёт систематический дрейф энергии (через 10⁴ оборотов планета «улетает» без причины), симлектический сохраняет фазовый объём и даёт ограниченную осцилляцию энергии вместо дрейфа.

### 5.2 WHFast

Основной интегратор L1 — **WHFast** (Wisdom–Holman Fast): расщепление `H = H_Kepler + H_perturbation` и шаг kick–drift–kick (полушаг возмущений → кеплеровский дрейф → полушаг возмущений). Реализация: демократические геоцентрические координаты (сумма импульсов = 0), симлектический корректор 5-го порядка на границах активации и при снятии якорей, сортировка тел по массе для детерминизма. Границы: иерархические системы, `e < 0,9`, без тесных сближений.

Шаг ограничен каноном 7.1:

```
dt ≤ min( T_min/1000, 3600 с ),   T_min = 2π√(a_min³/μ)
```

где `T_min` — минимальный орбитальный период, `a_min` — наименьшая большая полуось, `μ = G(M_star + m)` — гравитационный параметр. Для Меркурия `dt ≤ 7 600 с`, кап 3 600 с перекрывает; для горячего юпитера с периодом 3 суток `dt ≤ 260 с`.

### 5.3 IAS15

**IAS15** — адаптивный интегратор 15-го порядка (Гаусс–Радфорд, реализация REBOUND). Не симлектичен, но контролирует ошибку на каждом шаге (машинная точность). Применяется при сближениях, гиперболических орбитах, захватах, приливах, у компактных объектов, для валидации и на Полигоне (19). Дороже WHFast в 3–20 раз на тело — включается точечно.

### 5.4 Переключение WHFast ↔ IAS15

| Условие | Порог | Действие |
|---|---|---|
| Сближение | < 5 взаимных радиусов Хилла | IAS15 на время сближения |
| Эксцентриситет | `e > 0,9` | IAS15 |
| Скорость сближения | `v_rel > 0,1 v_esc` | IAS15 + подшаг столкновений (8.1) |
| Ошибка шага | > 10⁻¹² относительной | уменьшить dt; при повторе — IAS15 |
| Гиперболическая орбита | удельная энергия > 0 | IAS15 |
| Остаток сверхновой | появился компактный объект | IAS15 на 10⁴ шагов |

Переключение переносит позицию и скорость точно; корректор при возврате не применяется, чтобы не внести скачок.

### 5.5 1PN и приливы

Прецессия перицентра за оборот:

```
Δϖ = 6πGM/(a(1 − e²)c²)
```

где `M` — масса центрального тела, `a` — большая полуось, `e` — эксцентриситет, `c` — скорость света. Для Меркурия — 5,0×10⁻⁷ рад/оборот = 43″/век (наблюдаемое значение, бесплатный тест корректности). Приливы: `Δa ≈ 2GM_p·R_m/r³`, диссипация через `k₂/Q ~ 10⁻³–10⁻²` для каменных тел — приливный разогрев, раскрутка, разрушение (10.2).

## 6. Орбитальные элементы и эфемериды вне bubble

### 6.1 Элементы

Состояние тела — `r`, `v` в S (double). Для хранения и интерфейса — элементы Кеплера: `a`, `e`, `i`, `Ω`, `ω`, `M`. Из элементов в состояние:

```
n = √(μ/a³)
M = n·(t − t₀)
M = E − e·sin E            (уравнение Кеплера, Ньютон, допуск 10⁻¹⁴)
r = a(1 − e·cos E)
T = 2π√(a³/μ)
```

где `n` — среднее движение, `μ = G(M + m)`, `E` — эксцентрическая аномалия, `t₀` — эпоха перицентра, `T` — период. Начальное приближение `E₀ = M + e·sin M`, до 8 итераций; при `e > 0,95` — бисекция. Обратное преобразование: `h = r × v`, `e_vec = (v × h)/μ − r/|r|`, `a = 1/(2/|r| − v²/μ)`; полностью — в [18](18-glossary-formulas.md).

### 6.2 Модель эфемерид

Неактивные системы L0 хранит как **элементы + секулярные поправки**, аппроксимированные полиномами Чебышёва на 100-летнем отрезке:

```
a(t), e(t), i(t), Ω(t), ω(t), M(t) = Σ c_k·T_k(τ),   τ ∈ [−1, 1]
```

где `T_k` — многочлены Чебышёва, `c_k` — коэффициенты (6–8 на элемент), `τ` — нормированное время. Коэффициенты генерируются один раз: прогон IAS15 на 100 лет с шагом 1 сутки → аппроксимация. Секулярные поправки: прецессия узла и перицентра от гигантов, вековое изменение `a` от приливов. Хранение — 384 байта на тело, ≤ 10 МБ на галактику; мелкие тела поясов коэффициентов не имеют (статистический слой: плотность, масса).

Допуск канона: **≤ 10⁻⁴ а.е. на 10 лет** (канон 6.3). Для внешних планет — масштабирование `10⁻⁴·(t/10 лет)²` (предложение 23.2).

### 6.3 Якоря

При демоушене L1 пишет разницу фактического состояния и модели:

```
anchor = (r − r_eph(t_down), v − v_eph(t_down))
```

где `t_down` — момент деактивации. При активации якорь прибавляется и затухает за `T_blend = 0,25·T_min`:

```
r(t) = r_eph(t) + anchor·(1 − s),   s = clamp((t − t_up)/T_blend, 0, 1)
```

Непрерывность C⁰/C¹ сохраняется, центр масс корректируется массово-взвешенно, паразитного дрейфа барицентра нет.

## 7. Активация и деактивация без скачков

**Bubble** — сфера активации игрока плюс сферы наблюдения событий.

| Контекст | Радиус | Уровни |
|---|---|---|
| Игрок в системе | 200 а.е. (канон 6.3) | L1 + L2 |
| Игрок на планете | зона + 50 км | L3 + L2 (орбита) |
| Событие (сверхновая, импакт, бой) | 10⁴ а.е. от эпицентра | L1 |
| Дальний обзор сенсоров | 0,5–5 св. лет | L0-эфемериды |

Одновременно на L1 — не более 2 систем (Steam Deck — 1). Приоритет очереди: игрок → бой с игроком → сюжетное событие → событие с экономическими последствиями → наблюдение.

**Промоушен (L0 → L1):** триггер → оценка эфемерид на `t_act` → инстанцирование ≤ 500 тел (крупные — N-body, мелкие — статистический слой) → прогрев 64 шага WHFast (рендер интерполирует) → применение якорей и проверка импульса → передача владения.

**Демоушен (L1 → L0):** снятие состояния на `t_down` → вычисление якорей → подгонка Чебышёва по последним 100 шагам → пометка `eph_dirty` при расхождении > допуска → освобождение памяти.

**Метрика бесшовности:** визуальное смещение ≤ 1 пиксель (для планеты ≤ 0,005 а.е. на 200 а.е., для корабля ≤ 150 км на 1 000 км); скачок центра масс ≤ 10⁻⁹ а.е.; скачок энергии ≤ 10⁻⁶ относительной; отсутствие дубликатов ID — жёсткий assert.

## 8. Детекция столкновений и фрагментация

### 8.1 Детекция

**Broadphase:** свип-энд-прун по оси наибольшего разброса либо octree при > 2 000 тел, обновление раз в 4–16 шагов. **Narrowphase:** сферические оболочки `R_i + R_j`, для вытянутых тел — эллипсоид. **Подшаги:** дробление до

```
dt_sub ≤ 0,5·(R_i + R_j)/v_rel
```

окно 0,1–60 с (канон 6.3). Для гиперболических сближений момент контакта решается аналитически (линеаризация по скорости).

### 8.2 Q/D*

```
Q = μ·V²/(2·M_sum),   μ = m₁m₂/(m₁ + m₂),   M_sum = m₁ + m₂
Q_D* = Q_s·(R/1 км)^(−0,36) + Q_g·(R/1 км)^(1,36)
```

где `Q` — удельная энергия удара, `μ` — приведённая масса, `V` — относительная скорость, `M_sum` — суммарная масса, `R` — радиус мишени, `Q_s` — прочность при `R = 1 км` (камень 10⁵–10⁶ Дж/кг, лёд в 5–10 раз меньше, металл в 3–10 раз больше), `Q_g` — гравитационный член при `R = 1 км` (10²–10³ Дж/кг). `Q_D*` определён как энергия, при которой крупнейший осколок = 50% массы. Обе константы — балансные ручки ([12](12-balance-testing-telemetry.md)).

| Условие | Исход | Крупнейший осколок |
|---|---|---|
| `Q < 0,1·Q_D*` | кратер | 100% |
| `0,1·Q_D* ≤ Q < Q_D*` | частичное дробление | 50–99% |
| `Q_D* ≤ Q < 2·Q_D*` | катаклизм | `M_LR/M_tot = 1 − Q/(2Q_D*)` |
| `Q ≥ 2·Q_D*` | полное разрушение | 0 (пыль) |

### 8.3 Осколки и сохранения

- **Количество:** `N = clamp(2 + ⌊(Q/Q_D* − 1)·50⌋, 2, 64)`; остальное — пыль (10–40% массы: в L2 ≤ 5 000 частиц по канону 12.1, в L1 — оптическая толща).
- **Массы:** `dN/dm ∝ m^(−α)`, `α = 1,5–2,0`.
- **Скорости:** `v_ej ~ √(2·(Q − Q_D*))`, конус вокруг оси удара.

Проверки каждого акта:

```
Σm_i = M_tot
Σm_i·v_i = p₀
Σ(m_i·(r_i × v_i) + I_i·ω_i) = L₀
E_kin + E_bind + E_heat + E_rad = E₀
```

где `I_i`, `ω_i` — момент инерции и угловая скорость осколка. Невязка ≤ 10⁻⁶ от `E₀`; при превышении пересчитывается дисперсия скоростей, а не массы.

### 8.4 Уровни энергии

Для визуала кратера используется `D ≈ 1,8·(ρ_i/ρ_t)^(1/3)·L^0,78·v^0,44·g^(−0,22)`, где `D` — диаметр кратера, `L` — диаметр ударника, `v` — скорость, `g` — тяжесть мишени; для 10-км ударника при 20 км/с на Земле `D ≈ 112 км` (коэффициент калибруется).

| Энергия | Тротил | Пример | Последствия |
|---|---|---|---|
| 10¹⁵ Дж | 0,24 Мт | тактический заряд | локальные разрушения |
| 10¹⁷ Дж | 24 Мт | 1 кг на 0,9c (канон 8.3) | город |
| 4,2×10²³ Дж | 10⁸ Мт | Чиксулуб (канон 8.1) | континентальная катастрофа |
| 2,08×10²⁴ Дж | 5×10⁸ Мт | 3 800 т на 0,99c | вымирание биосферы |
| 2,24×10³² Дж | 5×10¹⁶ Мт | энергия связи Земли | разрушение планеты |
| 10⁴⁴ Дж | 2×10²⁸ Мт | сверхновая | уничтожение системы |

## 9. Сверхновые

**Прародители:** массивные звёзды > 8 M☉ (тип II, канон 8.4), белые карлики с аккрецией до предела Чандрасекара 1,4 M☉ (Ia, ~30% событий), коллапсары > 25 M☉ (редкие, «знаковые» системы). Каноническая энергия — **10⁴⁴ Дж**; распределение (предложение 23.1): 90% в кинетику оболочки, 9% в излучение, 1% в нейтрино.
**Ударная волна:**

```
v_sh = √(2·E_kin/M_ej)
```

где `E_kin` — кинетическая энергия оболочки, `M_ej` — масса выброса. Канонный диапазон 10 000–30 000 км/с (канон 8.4) соответствует `M_ej ≈ 0,1–1 M☉` при `E_kin = 10⁴⁴ Дж`. Через год `R ≈ v_sh·t` ≈ 0,3 св. года; дальнейшее расширение описывается моделью Седова `R(t) = 1,15·(E·t²/ρ_ISM)^(1/5)` с `ρ_ISM ≈ 10⁻²¹ кг/м³` — это даёт замедление и отложенность последствий.

**Прогноз 3–30 дней:**

| Предвестник | За сколько дней | Надёжность |
|---|---|---|
| Нейтринный фон | 30–20 | 80% |
| «Дрожание» фотосферы | 20–10 | 65% |
| Спектральные аномалии, потеря массы | 10–3 | 50% (Ia — 30%) |
| Финальный предвестник | 3–0,1 | 95% |

Надёжность — вероятность получения предупреждения; ложная тревога — 1 на 40. Источник данных — сенсоры корабля и обсерватории цивилизаций (доступ зависит от репутации, [09](09-reputation-diplomacy.md)).
**Поражение.** Поток излучения:

```
F = E_rad/(4π·d²)
```

где `E_rad ≈ 9×10⁴³ Дж` — энергия в излучении, `d` — расстояние. На 5 св. годах `F ≈ 3,6×10⁹ Дж/м²`, на 30 св. годах `≈ 10⁸ Дж/м²`.

| Зона | Расстояние | Эффект |
|---|---|---|
| Летальная | < 5 св. лет | смерть без щита, атмосферы сорваны |
| Тяжёлая | 5–15 св. лет | гибель биосферы, отказ электроники |
| Средняя | 15–50 св. лет | климатический сдвиг, радиация |
| Обнаружение | > 50 св. лет | только нейтрино и вспышка |

В каноне зона сжата до «соседних 1–2 систем» (8.4): событие обрабатывается только для систем в графе коридоров. **Щит «Гелиос» (класс V)** — магнитоплазменный барьер с эффективностью 99,9% по потоку, расходует до 60% мощности реактора (180 ТВт); без него — смертельные повреждения (канон 8.4). Остаток: нейтронная звезда (10–12 км, 1,4–2,2 M☉) или ЧД (> 2,5 M☉); туманность расширяется и служит источником экзотики.

## 10. Чёрные дыры

**Радиус Шварцшильда:**

```
Rs = 2GM/c²
```

где `G` — гравитационная постоянная, `M` — масса, `c` — скорость света. Канон 8.5: Солнце — 2,95 км, Земля — 8,9 мм, ЧД 10⁸ M☉ — ≈2 а.е. (точно 1,97). В игре 18 звёздных ЧД и 1 сверхмассивная в ядре (канон 6.6).

**Приливное разрушение:**

```
Δa ≈ 2GM·r/R³,   R_spag = (2GM·r/a_crit)^(1/3)
```

где `r` — половина длины тела, `R` — расстояние до ЧД, `a_crit` — предел прочности конструкции (для корабля ≈ 100 g = 981 м/с² с учётом компенсаторов). Для ЧД 10 M☉ и корабля 140 м: `R_spag ≈ 7 200 км` = 245 Rs — задолго до горизонта. Для 10⁸ M☉: `R_spag ≈ 0,01 а.е.` — глубоко внутри горизонта (1,97 а.е.). Геймплей: у звёздной ЧД корабль рвётся снаружи, у сверхмассивной проходит горизонт целым.

**Предел Роша** для спутника (канон 8.6):

```
d_Roche ≈ 2,44·R_p·(ρ_p/ρ_s)^(1/3)
```

где `R_p` — радиус планеты, `ρ_p`, `ρ_s` — плотности планеты и спутника; применяется к лунам, астероидам и перенаправляемым телам (13).

**Аккреция и джеты:**

```
L = η·Ṁ·c²,   L_Edd = 4πGM·m_p·c/σ_T ≈ 1,26×10³¹·(M/M☉) Вт
```

где `η` — эффективность (5,7% для Шварцшильда, до 42% для вращающейся, в игре 10%), `Ṁ` — темп аккреции, `m_p` — масса протона, `σ_T` — томсоновское сечение. Джеты: 0,9–0,99c, мощность 10³⁸–10⁴⁰ Вт, конус ~10⁻⁴ ср. Тень ЧД — `≈ 5,2 Rs`, фотонная сфера — `1,5 Rs` (шейдер — [11](11-art-ux-audio-narrative.md)).

**Гравитационные пращи:**

```
Δv = 2·v_∞·sin(δ/2),   tan(δ/2) = GM/(b·v_∞²)
```

где `v_∞` — скорость на бесконечности относительно планеты, `δ` — угол поворота скорости, `b` — прицельный параметр; максимум `Δv ≈ 2v_planet` (Юпитер: 13,1 км/с → до 26 км/с). У ЧД эффективность выше, но у звёздной мешает приливный барьер; безопасная праща — только у сверхмассивной. Захват — потеря энергии на приливы и динамическое трение:

```
ΔE ≈ 4πG²M²ρ·lnΛ/v²
```

где `ρ` — плотность окружающих тел, `lnΛ` — кулоновский логарифм (фиксирован 10).

## 11. Пульсары, белые дыры, квазары

| Объект | Кол-во | Модель | Роль в игре |
|---|---|---|---|
| **Пульсар** | 9 | вращение `P`, магнитная ось под углом, лучи; `B ≈ 3,2×10¹⁹·√(P·Ṗ)` Гс | навигационные маяки, опасность вблизи |
| **Белая дыра** | 3 | выброс материи, нестабильность горизонта, 10⁴⁰–10⁴² Дж/с | аномалия, источник экзотики |
| **Квазар** | 4 | активное ядро, джеты 0,9–0,99c, 10³⁸–10⁴⁰ Вт | политический фактор, запретные зоны |
| **Сверхмассивная ЧД** | 1 | ядро Галактики, 10⁸ M☉ | финал сюжета, максимальный пращ |

Пульсарный маяк: положение по времени прихода импульсов, `σ ≈ c·σ_t·√N` (`σ_t` — точность таймера 10⁻⁹ с, `N` — число импульсов) — дешёвая навигация без FTL. Белые дыры нельзя использовать как двигатель или оружие; попытка — сюжетная катастрофа.

## 12. Релятивистский удар

```
E = (γ − 1)·m·c²,   γ = 1/√(1 − β²)
```

где `m` — масса, `β = v/c`, `c` — скорость света. Таблица канона 8.3 с добавленными величинами:

| Масса | Скорость | γ | Импульс, кг·м/с | Энергия, Дж | Тротил |
|---|---|---|---|---|---|
| 1 кг | 0,90c | 2,29 | 6,2×10⁸ | 1,16×10¹⁷ | ~28 Мт |
| 1 кг | 0,99c | 7,09 | 2,1×10⁹ | 5,47×10¹⁷ | ~131 Мт |
| 1 т | 0,99c | 7,09 | 2,1×10¹² | 5,47×10²⁰ | ~13 Гт |
| 3 800 т | 0,99c | 7,09 | 8,0×10¹⁵ | 2,08×10²⁴ | ~5×10⁸ Мт |

- **По планете:** 2,08×10²⁴ Дж ≈ 5 Чиксулубов — вымирание биосферы, но **не** разрушение планеты (энергия связи Земли в 10⁸ раз больше); максимальный Infamy и «галактическое эмбарго» (канон 8.3, [09](09-reputation-diplomacy.md)).
- **По звезде:** звезда не разрушается (энергия связи Солнца 2,3×10⁴¹ Дж), но возникает вспышка и выброс — «звёздная буря»: сбой сенсоров, гибель ближайших планет.
- **По кораблю:** прямое попадание — уничтожение; промах на 100 км — ЭМИ и тепловой импульс.

Поглощение энергии — экспоненциальное вдоль траектории: `dE/dx ≈ −E/λ`, где `λ` — длина пробега (атмосфера 10–100 г/см², корпус 1–10 г/см²).

## 13. Перенаправление астероидов

```
Δv = I/m = F·t/m,   Δs ≈ 3·Δv·t_дрейфа,   Δv_req = Δs/(3·t_дрейфа)
```

где `I` — импульс тяги, `F` — тяга, `t` — время работы, `m` — масса астероида, `Δs` — требуемое смещение. Второе соотношение — следствие изменения большой полуоси и периода при малом тангенциальном импульсе.

**Пример.** Сместить `10¹² кг` на 6 371 км за 10 лет (`3,16×10⁸ с`): `Δv_req = 6,7×10⁻³ м/с`, импульс `6,7×10⁹ Н·с`, при 10 двигателях по 100 Н — 78 суток работы, рабочее тело `m_prop = m·Δv/v_e = 2,2×10⁵ кг` при `v_e = 30 км/с`, энергия `0,5mv² = 2,2×10⁷ Дж` (мизер — сложность в логистике). Методы: ионный буксир (точно, медленно), масс-драйвер (сильная тяга, нужна инфраструктура), ядерный толчок (быстро, но загрязнение и Infamy), гравитационный пращ (бесплатно, окно раз в годы), релятивистский удар (мгновенно, но это уничтожение и максимальный Infamy).

## 14. Энергия разрушения планет

```
E_bind = 3GM²/(5R)
```

где `M`, `R` — масса и радиус тела. Опорные значения: Луна — 1,24×10²⁹ Дж, Меркурий — 1,79×10³⁰, Марс — 4,86×10³⁰, Земля — **2,24×10³²** (канон 8.1), Юпитер — 2,02×10³⁶, Солнце — 2,28×10⁴¹ Дж. Пороги: срыв атмосферы — 10²⁶–10²⁷ Дж, испарение океанов — 10²⁷–10²⁸, расплавление коры — 10²⁹–10³⁰, полное разрушение — `E_bind` (пояс обломков).

Следствие для баланса: **релятивистский корабль убивает биосферу, но не планету**; разрушение планеты — событие уровня сверхновой или накопленного удара, доступное поздним технологиям ([07](07-civilizations-tech-politics.md)).

## 15. Терраформирование

Канон 8.7: бюджет 10²⁰–10²⁶ Дж, сроки 10–200 игровых лет. Энергия:

```
E = m_atm·(Δh + c_p·ΔT + L_vap) + P·V
```

где `m_atm` — масса доставляемого/испаряемого газа, `Δh` — удельная работа подъёма в поле тяжести, `c_p` — теплоёмкость, `ΔT` — нагрев, `L_vap` — теплота парообразования, `P·V` — работа расширения (для тонкой атмосферы мала). Мощность `P = E/t`; для Марса (до 1 бара, `m ≈ 3,9×10¹⁸ кг`, `E ≈ 10²⁵ Дж`) за 100 лет нужно `≈ 3,2×10¹⁵ Вт` — около 18 реакторов по 180 ТВт (канон 9) или сеть орбитальных зеркал.

| Этап | Доля энергии | Срок | Риск провала |
|---|---|---|---|
| Нагрев до таяния | 5–10% | 5–20 лет | 10% |
| Доставка летучих | 40–60% | 20–80 лет | 25% |
| Стабилизация атмосферы | 20–30% | 20–50 лет | 20% |
| Инокуляция биосферы | < 5% | 10–30 лет | 40% |

Терраформирование — проект цивилизаций и флотов, а не одна кнопка ([10](10-planets-landing.md), [07](07-civilizations-tech-politics.md)).

## 16. Устойчивость и точность при ускорении времени

Ключевой принцип: **ускорение времени не меняет шаг интегратора** — оно меняет, сколько шагов выполняется за секунду (3.2). Точность определяется шагом и числом тел, а не множителем 1×…40×: при 40× те же 24 шага по 3 600 с идут за 1,2 с вместо 48 с.

| Метрика | Порог | Реакция |
|---|---|---|
| Дрейф энергии за 1 000 оборотов | ≤ 10⁻⁹ | warn при 10⁻⁸, assert при 10⁻⁶ |
| Дрейф импульса | ≤ 10⁻¹² | assert |
| Шаг против периода | `dt ≤ T_min/1000` | жёсткий кап |
| NaN/Inf | любое | изоляция тела, лог, рекавери |
| Расхождение с эфемеридой | > 10⁻⁴ а.е. | пересчёт якорей |
| Lyapunov-время < 100 лет | хаос | пометка «хаотическая», эфемериды на 20 лет |

Ошибка растёт быстрее при высоком `e`, тесных сближениях, резонансах и больших массах. Горизонт 40–120 игровых лет (канон 5) покрывается; 200 лет нужны только терраформированию.

## 17. Детерминизм и воспроизводимость

1. **Фиксированный порядок** обхода тел (монотонный ID) и порядок суммирования; никакой итерации по `Dictionary` в горячих путях.
2. **Отдельные PCG64-потоки** на домен: `universe`, `system`, `encounter`, `fragment`, `weather`, `economy`, `politics`; счётчики в сейве.
3. **Собственные `sin`, `cos`, `sqrt`, `atan2`** в double: libm различается между платформами.
4. **Состояние интегратора — часть состояния:** коэффициенты корректора WHFast, история IAS15, кэш ускорений.
5. **Golden-hash** позиций на фиксированных тиках (каждые 1 000 шагов); несовпадение — провал CI.
6. **Сейв:** версия схемы, RNG, очередь событий, якоря; инкрементальные чанки ≤ 400 МБ (канон 17).

## 18. Производительность

| Операция | Стоимость | Бюджет |
|---|---|---|
| L0: экономика/политика (2 500 систем) | 8–15 мс | 20 мс |
| L0: эфемериды на сутки | 2–4 мс | входит в 20 мс |
| L1: возмущения 500 тел (N², отсечение по Хиллу) | 1,5–3 мс | 8 мс/шаг |
| L1: столкновения, broadphase | 0,3–1 мс | — |
| L2: 2 000 сущностей | 2–4 мс | 4 мс/кадр |
| L3: SDF-разрушаемость | 3–6 мс | 6 мс/кадр |

**LOD физики:** Full (N-body, столкновения, приливы — bubble, ≤ 500 тел) → Reduced (планеты и крупные луны, пояса как кольцо массы) → Kepler (аналитические элементы) → Statistical (плотность, масса) → Frozen (только события). Параллелизм — `IJobParallelFor` в Burst с детерминированным разбиением; рендер интерполирует между симуляционными тиками.

## 19. Тестовый стенд-плейграунд

Отдельный инструмент «**Полигон физики**» (`SimLab`), не часть игры; доступен из dev-сборки и headless-режима ([12](12-balance-testing-telemetry.md)). Функции: «бросание планет» (произвольные масса, радиус, скорость); «столкновение с Солнцем» (сброс тела с выбором скорости); стенд ЧД (спагеттификация, праща, захват, аккреция); кнопка «взорвать звезду» (предвестники, волна, щит); ускорение 1×…40× с графиком энергии и импульса; реплеи по seed; метрики против эталонного IAS15-прогона. Приёмка: 60 FPS при 500 телах, отсутствие скачков активации, полный цикл «импакт → фрагментация → пояс» без NaN.

## 20. Валидация против JPL Horizons

Игра не обязана воспроизводить Солнечную систему, но интегратор обязан быть корректным. В `SimLab` есть **эталонная Солнечная система** (реальные массы, элементы J2000). Процедура: загрузить векторы Horizons на эпоху J2000 → прогнать WHFast/IAS15 на 1, 10, 100 лет → сравнить `Δr = |r_sim − r_ref|` и угловое `Δθ = Δr/d` → RMS и максимум в CI. Допуски (предложение 23.3):

| Горизонт | Внутренние планеты | Внешние планеты | Луна |
|---|---|---|---|
| 1 год | ≤ 10⁻⁶ а.е. | ≤ 10⁻⁵ а.е. | ≤ 10⁻⁶ а.е. |
| 10 лет | **≤ 10⁻⁴ а.е.** (канон 6.3) | ≤ 10⁻⁴ а.е. | ≤ 10⁻⁴ а.е. |
| 100 лет | ≤ 10⁻³ а.е. | ≤ 10⁻² а.е. | не нормируется (хаос) |

Угловой допуск на 10 лет — ≤ 0,1″ для внутренних планет. Для Меркурия обязательна 1PN (5.5): без неё тест проваливается на 43″/век. Отдельно валидируются фрагментация (против аналитики Q/D*: при `Q = Q_D*` `M_LR` = 50%) и эфемериды (против 100-летнего прогона IAS15).

## 21. Крайние случаи

| Случай | Проблема | Решение |
|---|---|---|
| Тесная двойная | иерархия, `e → 1`, Kozai–Лидова | IAS15, шаг ≤ T_min/1000, проверка устойчивости при генерации |
| Резонанс | усиление ошибок, хаос | пометка «хаотическая», эфемериды на 20 лет |
| Хаос (Lyapunov < 100 лет) | расхождение после активации | длинный прогрев, якоря, запрет предсказаний в интерфейсе |
| Убегающее тело | гиперболическая орбита | кеплеровский LOD; за 3 радиуса Хилла — исключение из N-body |
| Удар «в лоб» | сингулярность `r → 0` | мягкая гравитация `ε = 10³ м` только численно; контакт — отдельно |
| Потеря > 30% массы пояса | перестройка орбит (канон 8.2) | пересчёт эфемерид, событие «сейсмическая перестройка» |
| ЧД в системе | нет аналитики Кеплера | 1PN + IAS15 вблизи, кеплеровский LOD вдали |
| Игрок при 40× в сближении | нехватка шагов | автопауза на событиях (канон 7.2), принудительное замедление |
| Сейв посреди фрагментации | состояние осколков | транзакция: сейв после акта либо консервация списка |
